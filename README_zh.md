# 地下城与勇士 台服原生启动器 (dnflogin1)

🚀 **Core Technical Stack:** `C++23` | `CMake / Ninja` | `OpenSSL 3.x` | `MySQL 5.0 SDK`

[English](./README.md) | **简体中文***

一个基于 C++23、CMake 和 OpenSSL 3.x 构建的 DNF（台服原端）企业级模块化单机/联机启动器。

本架构彻底剔除了传统私服繁琐且不安全的网页登录器网关，采用纯净的原生命令行密文对流技术，具备高度的安全防线与极佳的未来图形界面（GUI）扩展能力。

---

## 📂 项目模块与目录导航

为了保持代码的绝对纯净与高内聚，本项目采用了严格的 **“资产-源码分离”** 与 **“多应用独立解耦”** 架构：

* **`src/core/`** - 底层核心静态库 (`dnf_core.lib`)。包含自建 RSA 密码学握手、MySQL 安全数据层、路径解析与 Ticket 生成。
* **`src/game/`** - 游戏控制静态库 (`dnf_game.lib`)。利用纯净的 Win32 进程 API 挂载和拉起游戏子进程。
* **`src/apps/`** - 多应用入口层。控制台版本 (`cli/`) 已完美独立。未来新增图形界面版本时，可一键扩展 `gui/` 模块而无需改动任何底层核心。
* **`res/`** - 编译期资产目录。包含 Windows 资源脚本 `.rc` 以及在编译期间通过内存安全封死在 EXE 内部的私钥资产。
* **`tool/`** - 外部诊断工具包。包含 Kali Linux 环境下使用的自主研发解密验证脚本 `decrypt.py`。
* **`login/doc/`** - 详尽的技术、开发与运维文档。

## 🚀 开发者快速上手（10秒极速通关）

如果你本地已经配置好了环境，可以直接在 **`login/`** 目录下通过以下一键自动化流水线进行开发编译和成品分发：

```bash
# 1. 进入项目工作目录
cd login

# 2. 编译 Release 线上纯净版本（产物自动规整至 out/bin/Release/）
build-release.bat

# 3. 生成绿色免安装 ZIP 发布包（最终成品一键自动提取至 out/package/）
scripts/pack-zip.bat

# 4. 生成带桌面快捷方式的官方安装向导（最终成品一键自动提取至 out/package/）
scripts/pack-installer.bat
```
